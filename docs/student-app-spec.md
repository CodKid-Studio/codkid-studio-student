# CodKid Studio 生徒アプリ 仕様（要件定義書からの抜粋）

このファイルは「CodKid Studio 要件定義書(ベース)」のうち、生徒アプリに関わる部分だけを抜き出したものです。
このリポジトリは公開のため、料金・契約・業務の情報は含めていません。全文は非公開リポジトリにあります。

## 1. 目的

CodKid Studio は、Scratch を内部に組み込んだ子ども向けプログラミング学習アプリです。
このリポジトリは、その中の **生徒アプリ**(Scratch エディタのフォーク)です。
授業・出欠・教材管理などの運営機能は、別の自社 API と管理画面が持ちます。生徒アプリは API 経由でそれらとつながります。

### 生徒アプリが解決する課題

| # | 課題 | 解決方針 |
|---|---|---|
| 1 | 授業で使わないブロックを非表示にできない | 教材ごとに、カテゴリ単位・ブロック単位で表示を制御する |
| 2 | My Block がスプライトごとに表示され、子どもが中身を変更できてしまう | 全スプライト・全生徒共通で使える、中身を開けない「先生ブロック」を提供する |
| 3 | バージョン管理が難しい | 自動保存 + 保存点(Save point) + 教材のスターター版 |
| 4 | iPad での文字・数字入力が難しい | テンキー、ワードピッカーなどの入力補助 |
| 5 | 生徒アカウントが Scratch 頼み | 自社の認証。生徒はキーボード不要のログイン |
| 6 | 子ども同士の安全なシェア・いいねがない | クラス内限定ギャラリーとスタンプ(コメントなし) |

## 2. 前提

- 主な生徒は小学3〜5年生。授業言語は英語。主な端末は iPad。
- 標準の授業は 180 分(7フェーズ:Warm up、Play、Understand、Break、Build、Arrange、Share)。
- 授業は運営者(導入先の先生)が行う。運営者が「レッスン開始」を押すと、生徒側でその教材が開く。

## 3. 機能要件(生徒アプリ)

優先度:Must(初期リリース必須)、Should(初期に入れたい)、Could(後回し可)

| ID | 機能 | 要件 | 優先度 |
|---|---|---|---|
| S-01 | ログイン | クラスを選び、名前をタップし、絵3枚を順にタップしてログインする。キーボードは使わない。QR 付きログインカードにも対応する | Must |
| S-02 | ブロックエディタ | Scratch 3 のブロック・ペイント・音を使える。表示するブロックは教材ごとの設定に従う | Must |
| S-03 | 先生ブロック | Lesson カテゴリに表示する。全スプライトで使える。中身は表示せず変更もできない | Must |
| S-04 | ステージと実行 | 緑の旗、停止、スプライトのタップ。動作は本家 Scratch と同じにする | Must |
| S-05 | 入力補助 | 数字はテンキーとよく使う値、文字はワードピッカーで入力する。キーボード入力にも切り替えられる | Must |
| S-06 | ステップガイド | 教材の手順を1つずつ、教材に書いたヒントを添えて表示し、Back / Next で進む。手順のない教材は自由制作として開く | Must |
| S-07 | 自動保存 | 変更から数秒で保存する。通信が切れたら端末に一時保存し、復帰後に送る | Must |
| S-08 | 保存点 | ワンタップで保存点を作る。サムネイルと進み具合を自動で付ける。一言ラベルは任意(ワードピッカー) | Should |
| S-09 | 履歴から戻す | 保存点・自動保存・教材のスターターから戻せる。戻す前の状態も履歴に残す | Must |
| S-11 | 共有 | 作品名を付けてクラスギャラリーに出す。運営者の確認ありの設定なら承認後に公開する | Must |
| S-12 | ギャラリーとスタンプ | 自クラスの作品を遊べる。反応は GOOD / FANTASTIC / FUN / FAVORITE のスタンプのみ | Must |
| S-13 | .sb3 書き出し | 先生ブロックを通常の My Block に変換して書き出す。本家 Scratch で開いて動く | Should |
| S-14 | スプライトと背景 | 自社の素材ライブラリから追加する。Scratch の商標キャラクターは使わない | Must |

画面の文言はすべて英語で、短い単語・1行1指示とする。

### 先生ブロックの詳細(管理者側の要件から関係する部分)

- 定義は管理者がブロックで組む。
- 入力の種類は「数字 / 文字 / なし」から選び、既定値を決める。
- 先生ブロックが削除されても、それを使った既存の作品は動き続ける(削除は非表示扱いで、定義は残す)。
- 例:`Walk [1] steps`、`Add Score [1]`、`Start! Crabby says... [start]`

### ブロック表示設定の詳細

- 教材ごとに、カテゴリ単位・ブロック単位で表示を決める。
- 設定は管理者が作り、生徒アプリは教材を開くときに API から受け取る。

## 4. 非機能要件(生徒アプリに関係する部分)

数値は叩き台。

| 区分 | 要件 |
|---|---|
| 対応端末 | iPad Safari(最新版と1つ前の iPadOS)を主対象。PC の Chrome / Edge / Safari にも対応 |
| 画面 | iPad 横向きを基準。タップ対象は 44px 以上 |
| 性能 | 教室回線でも 5 秒以内に操作可能になる。ブロック操作・実行は本家 Scratch と同等 |
| 同時利用 | 1教室 30 台が同時にログイン・保存しても遅延しない |
| 通信断への耐性 | 通信が切れても編集を続けられ、復帰後に保存される。作品を失わない |
| アクセシビリティ | 色だけで情報を伝えない。文字のコントラストを確保する。文言は短い英語 |
| 言語 | 生徒画面は英語 |
| 保守性 | Scratch をフォークした部分と自社部分を分け、本家の更新を取り込みやすくする |
| 形式 | PWA |

## 5. データ(生徒アプリが扱うもの)

- 生徒の個人情報はファーストネームと所属クラスだけ。メールアドレスや生年月日は持たない。
- 作品の .sb3 とサムネイルは API 経由でストレージに保存する。生徒アプリは直接データベースに触れない。

## 6. ライセンス・商標・子どもの安全

- Scratch エディタのコードは AGPL-3.0(scratch-blocks は Apache-2.0)。著作権表示とライセンス文を製品内に残す。改変したソースは公開する。
- 「Scratch」の名前、ロゴ、Scratch Cat などのキャラクターは商標のため、製品名・画面・宣伝に使わない。標準の素材ライブラリも自社素材に置き換える。
- 共有は自クラス(または自校)内に限る。自由入力のコメント・チャットは持たない。
- 作品名など子どもが入力する文字には、不適切な語のフィルタをかける。
- 運営者の確認ありの設定では、承認するまで作品は他の生徒に見えない。

## 7. 用語

| 用語 | 意味 |
|---|---|
| 運営者 | 導入先で、生徒にアプリを使って教える人(先生) |
| 管理者 | 自社。教材を作り、システムを設定する |
| 教材 | 1つのゲーム制作単位。手順、ヒント、スターター、学習目標、ブロック表示設定を持つ |
| スターター | 生徒が教材を始めるときの初期状態の作品。版で管理する |
| 先生ブロック | 管理者が定義し、全スプライト・全生徒が使えるブロック。生徒は中身を見られない |
| 保存点(Save point) | 生徒がワンタップで残す作品の保存。サムネイル付き |
| 公開中の教材 | そのクラスの生徒がログインしたときに開く教材 |
| 自由制作(Free build) | 手順のない教材を開いたときの状態 |
| スタンプ | ギャラリーの作品への反応。GOOD / FANTASTIC / FUN / FAVORITE |
